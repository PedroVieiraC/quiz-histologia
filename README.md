# Quiz de Histologia · Sistema Digestório

Quiz em HTML (sem instalação) sobre as lâminas J1–J23 do sistema digestório: identificar estruturas marcadas, reconhecer a lâmina, técnicas de coloração e teoria. Cada questão traz o raciocínio. Ao final aparecem a média de acertos e os pontos fracos.

Para usar, abra o `index.html` ou o link do GitHub Pages.

Imagens: [Atlas de Histologia UFG – DHisto ICB-UFG](https://histologia.icb.ufg.br/diges.html), usadas conforme a permissão de cópia com indicação da fonte. As legendas foram removidas para o quiz.
